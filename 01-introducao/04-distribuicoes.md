# O que é uma distribuição Linux.

Conceito de *Distribuição Linux*: Uma distribuição Linux é um sistema operacional completo construído a partir do kernel Linux e de diversos componentes de software, como bibliotecas, utilitários GNU, gerenciadores de pacotes, ambientes gráficos e ferramentas de administração.
O que seria distribuição Linux: 

Diferente dos sistemas operacionais (SO) como o Windows e o macOS, que possuem código-fonte fechado e são desenvolvidos por uma única organização, o Linux tem código aberto, com várias organizações responsáveis por partes específicas do sistema. Isso nos permite montar o nosso próprio sistema combinando diferentes componentes.
Considerado um sistema modular, o que significa que é composto por partes que se combinam entre si.

Vejamos algumas dessas distribuições e algumas curiosidades:

***DEBIAN*** --> DEB vem de *"Debra"* e IAN vem de ***"Ian Murdock"***. Criador da distribuição. Colocou as iniciais do nome da sua ex-esposa e o seu juntos. (Uma grande história de amor que infelizmente acabou)

Uma curiosidade muito legal dessa distribuição é o nome de cada versão que representa um personagem de Toy Story. A versão atual é a ***trixie***, que é um dinossauro tricerátopo de brinquedo azul.

***UBUNTU*** --> Criado por ***"Mark Shuttleworth"*** e seu time de desenvolvedores, tinha a intenção de criar um sistema que fosse fácil para os usuários.

Uma curiosidade muito genial é a sua logo, que representa três pessoas de mãos dadas.

***FEDORA*** --> Uma distribuição que é patrocinada pela ***Red Hat***.

***SLACKWARE*** --> Uma distribuição bem antiga que foi lançada em 1993, foi criada somente por ***"Patrick Volkerding"***.

Existem centenas de distribuições Linux, cada uma com objetivos e características próprias. Algumas priorizam estabilidade, outras facilidade de uso, desempenho, personalização ou segurança.
