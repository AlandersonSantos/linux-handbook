# Licenças e Liberdade

## O que seria uma licença?

**Definição:** É um conjunto de normas que garante como alguém pode utilizar aquele produto ou serviço. Exemplos:

- **Licença comercial/proprietária** --> Você paga para ter o direito de uso de um software/serviço.
- **Licença adware/propaganda** --> O software é gratuito, mas exibe propagandas para se financiar.
- **Licença por assinatura** --> Você paga recorrentemente (mensal ou anual) para manter o acesso ao serviço.
- **Licença livre/open source** --> O usuário tem total liberdade para utilizar, modificar e distribuir o software de acordo com sua necessidade.

## Diferença entre: Livre vs. Grátis

O sistema **Linux** é livre, o que não significa necessariamente que ele seja gratuito. Um software livre pode ser vendido sem violar nenhuma regra. No passado, muitas distribuições eram vendidas em mídias físicas (CDs/DVDs) com manuais impressos. Hoje, o foco da comercialização mudou para a venda de suporte técnico, consultoria, embalagem e serviços agregados.

## As quatro liberdades essenciais

A licença mais famosa no mundo **Linux** é a ***General Public License (GPL)***. Ela dita juridicamente os quatro pilares que um software deve seguir para ser considerado verdadeiramente livre. Por convenção da cultura hacker, a lista começa do número 0 (zero):

| **PILAR** | EXPLICAÇÃO |
| :--- | :--- |
| 0 - **USO** | Deve garantir a liberdade de executar o programa para qualquer finalidade. |
| 1 - **ESTUDO** | Deve garantir o acesso ao código-fonte para estudar como o programa funciona e adaptá-lo às suas necessidades. |
| 2 - **REDISTRIBUIÇÃO** | O direito de redistribuir cópias do programa para ajudar outras pessoas. |
| 3 - **MELHORIA** | O direito de modificar o programa, aplicar melhorias e liberar essas melhorias para o público, beneficiando toda a comunidade. |

## Como o mercado monetiza com softwares livres?

A resposta é simples: vendendo serviços e expertise (mão de obra). Exemplos:

- Contratos de suporte técnico especializado.
- Consultoria de implantação e segurança de software.
- Customização do sistema para atender a necessidades específicas de uma empresa.
- Treinamentos e certificações profissionais.
