# Estrutura de comandos

No sistema operacional do **Linux**, os comandos têm uma grande semelhança:

Quais são os seus componentes:

|ELEMENTOS | FUNÇÃO |
|----------|--------|
|**Comando** | Diz qual programa será executado.|
|**Opções** | Elas fazem modificações nos comandos.|
| **Argumentos** | Informa qual arquivo, ou diretório/pasta ele vai atuar.|

## Exemplo 01

**Comando**: ***ls -l home/usuario***

| Parte | Significado|
|-------|------------|
| **ls** | Comando |
| **-l**| Opção |
| **home/usuario** | Argumento |

Comando **ls**, ele vai listar o conteúdo do seu diretório/pasta **home/usuario** utilizando o formato longo **-l**.

# Autocomplemento com a tecla: *tab*

Uma tecla muito utilizada para acelerar a sua digitação de comando, ela completa o código. Exemplo:

Imagine que você queira acessar o diretório **Download/** invés de escrever ele todo você pode colocar somente **Dow** no terminal e ele autocompletar.
Caso você clique no **tab** e não apareça nada, clique duas vezes seguidas, que ele vai lhe mostrar as opções que ele possui com o nome incompleto.

# Atalhos do Terminal

Os atalhos de teclado são fundamentais para aumentar a produtividade e agilizar a navegação dentro do terminal Linux.

| ATALHO | FUNÇÃO |
|--------|--------|
| **Ctrl + C** | Interrompe o comando em execução. |
| **Ctrl + L** | Limpa a tela do terminal. |
| **Ctrl + D** | Encerra a sessão atual do shell (logout). |
| **Ctrl + A** | Move o cursor para o início da linha. |
| **Ctrl + E** | Move o cursor para o final da linha. |
| **Ctrl + U** | Apaga do cursor até o início da linha. |
| **Ctrl + K** | Apaga do cursor até o final da linha. |
| **Ctrl + W** | Apaga a palavra anterior. |
| **Ctrl + R** | Pesquisa no histórico de comandos. |
| **TAB** | Autocompleta comandos e caminhos. |
