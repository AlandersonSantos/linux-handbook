# Comando `mv`

**Função**: Comando usado para mover arquivos ou alterar o nome de arquivos e diretórios. A **origem** é de onde sai o arquivo, o **destino** é para onde o arquivo vai, e o **resultado** pode ser a alteração do nome, a sobrescrita de um arquivo ou diretório, a movimentação de um diretório para um subdiretório ou a movimentação de arquivos para um diretório existente.

**Sintaxe**:

usuario@hostname:~$ mv [parâmetro] [origem] [destino]
