# Comando `cp`

**Função**: Comando usado para fazer cópias de um arquivo para outro ou copiar um ou mais arquivos para um diretório. Caso o arquivo de destino já exista, ele poderá ser sobrescrito. Se a cópia for feita para um diretório já existente, o arquivo será copiado para dentro dele, mas o diretório não será sobrescrito.

**Sintaxe**:

usuario@hostname:~$ cp [parâmetro] [arquivo1] [arquivo2]

usuario@hostname:~$ cp [parâmetro] [arquivos] [diretório]
